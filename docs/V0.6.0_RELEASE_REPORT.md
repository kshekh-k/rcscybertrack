## 4. Environment Limitation Note

During backend initialization and smoke testing, kernel netlink socket initialization returned:
`nftables validation failed: netlink: Error: cache initialization failed: Operation not permitted`

This error occurs exclusively because the build/test host container environment lacks `CAP_NET_ADMIN` / `CAP_NET_RAW` privileges required for live `nftables` rule insertion. All application mock and unit test isolation passes cleanly (136/136 tests). This is classified specifically as an **ENVIRONMENT LIMITATION — NOT AN APPLICATION REGRESSION**.
